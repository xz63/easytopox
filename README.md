This Project is developed by Xian Zhang Ph.d Yale school of medicine.
It is build on top of easytopo  (Fenghua Tian, Zi‑Jing Lin, and Hanli Liu, “EasyTopo: A toolbox for rapid diffuse optical topography based on a standard template of brain atlas,” Proc. SPIE 8578, Optical Tomography and Spectroscopy of Tissue X, 25 March 2013.)
it porforms Ttest for fNIRS or EEG data.
Each subject should have individual XYZ coordinate of channels in MNI space
Each Subject should have a beta values 
The program do ttest and render and report cluster of the activities <br>
testeasytopox.m  shows how to do ttest and render clusters where the cluster size and minimum subject number threshold can be chosen.
